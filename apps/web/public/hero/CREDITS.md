# Hero image credits

If you place a file named `pitch.jpg`, `pitch.png`, `pitch.webp`, or `pitch.avif`
in this directory, the landing page will use it as the hero background.

Record the source and license of whatever you add here. Two acceptable paths:

- AI-generated: note the tool and date. No attribution required, you own the output.
- CC0 / public-domain: note the source URL and license. Example:
  - Source: https://www.pexels.com/photo/... (Pexels License, free for commercial use)
  - Downloaded: 2026-10-11

Do not add editorial or rights-managed images (Getty, AFP, Premier League club
media, broadcast screenshots). They are not licensed for this use.
